# 🎀 Quinceañera de Sofía — Planning Portal

Portal de planeación para la quinceañera de **Sofía S.** el **26 de Diciembre de 2026**.

## ✨ Funcionalidades

- **Dashboard** — Countdown en tiempo real, progreso general, mini-calendario de Diciembre, tareas próximas
- **Checklist** — Lista de tareas con categorías, fechas límite, filtros por categoría y progreso visual
- **Padrinos** — Registro de padrinos/madrinas, montos prometidos y recibidos, progress bars por padrino
- **Presupuesto** — Control de gastos estimados vs reales, agrupados por categoría
- **Cursor voleibol** — Cursor personalizado con pelota de voleibol rosa
- **Figuras Guerrero** — Animaciones decorativas de figuras mixtecas/nahuas del estilo Guerrero
- **Modo oscuro/claro** — Toggle manual + respeta preferencia del sistema

## 🎨 Diseño

Paleta **rosa blush + dorado** inspirada en el vestido de Sofía (rosa claro).
Tipografía: **Playfair Display** (display) + **DM Sans** (cuerpo).
Figuras decorativas de arte Guerrero-Mixteco al 8-10% de opacidad.

## 🚀 Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:5000](http://localhost:5000)

## 🏗️ Stack

- **Frontend**: React + Vite + TypeScript
- **Backend**: Express + SQLite (via Drizzle ORM)
- **UI**: shadcn/ui + Tailwind CSS
- **Routing**: Wouter (hash-based)
